# 8128-ai-backend

1. Execute `npm init -y` in the terminal of a new folder
2. The folder with the `package.json` file is the root folder or project root
3. We have to install the following: `npm install express cors dotenv axios`
4. Install `npm install -g nodemon` to get Node Monitor
5. Launch: `nodemon`
6. `npm install @google/genai` and then `npm install-scripts approve -a` and then afterwards you have to run `npm install @google/genai` and then `npm rebuild`
